## 1. GNN / Citation Prediction

**위치**: `/home2/jmbyeon/developments/gnn/citation_prediction/`

**전체 목표**: 학술 논문(ACL) / 특허의 인용 수(citation count)를 GNN + 시계열 모델로 예측. 동적 이종 그래프(heterogeneous temporal graph)를 구성하고, 연도별 스냅샷 시퀀스에서 미래 피인용 수를 예측.

**공통 데이터**
- 소스: Semantic Scholar API (ACL 논문, 2017~2024), PatentsView (특허)
- 논문 피처: SciBERT [CLS] 임베딩 (768-dim), 저자 구조적 피처 5-dim
- 그래프 구성: Algorithm 1 (Optimal Subgraph Selection) — 최종 연도 LCC 기준 누적 anchor 점수가 가장 높은 연결 성분 선택
- 레이블: log(in-degree + 1) (= log 인용 수 + 1)
- 손실 함수: MAE (대부분), RMSLE (PTNS 계열)
- 평가: MAE, MALE, RMSLE
- 분할 방법 두 가지:
  - **Node split**: 전체 연도 사용, 노드를 60/20/20 랜덤 분할
  - **Temporal**: graph(T) → degree(T+1), 1-year ahead 예측

### 1-1. GCN+LSTM_2

**위치**: `gnn/citation_prediction/GCN+LSTM_2/`  
**날짜**: 2026-05-04 ~ 2026-05-08

#### 개요
논문 인용 수 예측의 기준선(baseline) 실험. 동종 그래프(homogeneous graph)에서 GCN(또는 TransformerConv) + LSTM 조합으로 연도별 시퀀스를 학습. 세 모델을 직접 비교.

#### 모델 구조 (models.py, models_transformer.py)

| 모델 | 구조 | 입력 | 출력 |
|------|------|------|------|
| **GCNModel** | 2-layer GCNConv → Linear head | (N, F), edge_index | (N, T) |
| **LSTMModel** | LSTM(1 layer) → Linear head | (N, T, F) 시퀀스 | (N, T) |
| **GCNLSTMModel** | GCNEncoder → LSTM → head | T개의 (N, F), edge_index | (N, T) |

- `GCNEncoder`: GCNConv(F→256) + GCNConv(256→256), 선택적 LayerNorm
- `GCNLSTMModel.encode()`: 각 연도 그래프를 GCN으로 인코딩 → (N, T, 256)
- `GCNLSTMModel.decode()`: LSTM(256→128) → Linear(128→1) → softplus
- `forward_with_state()`: LSTM hidden state를 반환해 train→val→test로 state 이어받기
- `models_transformer.py`: GCNConv 대신 TransformerConv(4-head, concat)으로 교체한 버전

#### 하이퍼파라미터 (config.py)
```
VENUES = ["ACL"]
YEAR_TRAIN_START=2017, YEAR_TRAIN_END=2021
YEAR_VAL_START=2022,   YEAR_VAL_END=2022
YEAR_TEST_START=2023,  YEAR_TEST_END=2024
GCN_HIDDEN=256, GCN_LAYERS=2, LSTM_HIDDEN=128
LR=0.001, BATCH_SIZE=256, MAX_EPOCHS=1000, PATIENCE=20
SCIBERT_MODEL="allenai/scibert_scivocab_uncased", SCIBERT_DIM=768
```

#### 입력 피처 (features.py)
- `abstract`: SciBERT [CLS] 토큰 768-dim (미출판 논문 → 0벡터)
- `author`: 저자 인용 누적 rank (연도별 1-dim, leakage 방지)
- `abstract+author`: 두 피처 concat (769-dim)

#### 그래프 구성 (graph_builder.py)
- 연도별 누적 방향성 인용 그래프 (DiGraph)
- 초록 없는 논문 제거
- Algorithm 1으로 2024년 기준 최적 subgraph 선택
- 최종 node_ids 고정 (2024 기준) → 미출판 연도에도 동일 노드셋 유지

#### 데이터 로드 (data_loader.py)
- Semantic Scholar bulk search + batch API (500개씩)로 ACL 논문 fetch
- 캐시(papers_raw.jsonl) 활용

#### 학습 방식 (train.py / train_node_split.py / train_temporal.py)
- **train.py (원본)**: train 2017-2021 → val 2022 → test 2023-2024, 전체 노드 사용. LSTM state를 train→val→test로 이어받음
- **train_node_split.py**: 전체 연도 2017-2024, 노드 60/20/20 분할. 미출판 노드 masking
- **train_temporal.py**: graph(2017-2021)→degree(2018-2022), graph(2022)→degree(2023), graph(2023)→degree(2024)

#### 결과물
- `training_curves_abstract.png`, `mae_per_timestep_abstract.png`, `top10_pred_gcn+lstm_abstract.png` (2026-05-04)
- `future_mae_abstract.png` (2026-05-04)
- node_split.json (공유 노드 분할)

#### 특이사항
- `main.py`에서 `--gnn gcn|transformer`, `--feature abstract|author|abstract+author`, `--version current|node_split|temporal` 옵션으로 조합 실험 가능
- `--layernorm` 옵션으로 LayerNorm 효과 비교

### 1-3. HetGNN Citation

**위치**: `gnn/citation_prediction/hetgnn_citation/`  
**날짜**: 2026-05-06 ~ 2026-05-07

#### 개요
GCN+LSTM_2와 동일한 encoder-decoder 구조에서 encoder만 이종 그래프(Heterogeneous)로 교체. paper-paper는 GATConv, paper-author는 SAGEConv 사용.

#### 모델 구조 (model.py)
- 클래스: `HetGNNLSTM`
- **Encoder** (`HetGNNEncoder`, 2-layer HeteroConv):
  - `(paper, cites, paper)` → GATConv(feat→h, heads=2)
  - `(paper, cited_by, paper)` → GATConv(feat→h, heads=2)
  - `(paper, written_by, author)` → SAGEConv((feat, feat)→h)
  - `(author, writes, paper)` → SAGEConv((feat, feat)→h)
  - aggr='mean', 각 레이어 후 ReLU
- **Decoder**: LSTM(hidden→lstm_hidden) → Linear(1) → softplus
- `encode()` → (N_paper, T, hidden), `decode()` → (N, T)
- `forward_with_state()` 지원

#### 그래프 (graph_builder.py)
- Hetero 스냅샷 구성
- paper feature: SciBERT + 저자 feature를 SciBERT 평균으로 사용 (후속 모델에서 구조적 feature로 개선)

### 1-5. HeteroLSTM (원형 이종 그래프 모델)

**위치**: `gnn/citation_prediction/hetero_lstm/`  
**날짜**: 2026-05-07 ~ 2026-05-14 (graph_builder.py: 2026-05-14)

#### 개요
GCN+LSTM_2를 이종 그래프(paper + author)로 확장한 핵심 모델. 이후 hetero_lstm_2/3/4, hetero_tcn, hetero_transformer 등 모든 후속 변형의 기반.

#### 모델 구조 (model.py)
- 클래스: `HeteroLSTM`
- **Encoder** (`HeteroEncoder`, 2-layer HeteroConv):
  ```
  Layer 1:
    (paper, cites, paper)       → TransformerConv(768→256, heads=4, concat=False)
    (paper, cited_by, paper)    → TransformerConv(768→256, heads=4, concat=False)
    (paper, written_by, author) → GATConv((768,5)→256, heads=2, concat=False)
    (author, writes, paper)     → GATConv((5,768)→256, heads=2, concat=False)
    aggr='mean', LayerNorm + ReLU

  Layer 2: 동일 구조, 입력 dim=256
    aggr='mean', LayerNorm + ReLU
  ```
  - 출력: `h['paper']` (N_paper, 256)

- **Decoder**: LSTM(256→128, batch_first=True) → Linear(128→1) → softplus
- `encode(snapshots)` → (N_paper, T, 256)
- `decode(z_seq)` → (N_paper, T)
- `forward_with_state(snapshots, hx)`: LSTM hidden state 이어받기 지원

#### 하이퍼파라미터 (config.py)
```
PAPER_FEAT_DIM=768, AUTHOR_FEAT_DIM=5, HIDDEN_DIM=256, LSTM_HIDDEN=128
TRANSFORMER_HEADS=4, GAT_HEADS=2
LR=1e-3, BATCH_SIZE=256, MAX_EPOCHS=1000, PATIENCE=20
```

#### 그래프 구성 (graph_builder.py — 2026-05-14 최종)
- **paper feature**: SciBERT 768-dim. 미출판(pub_year > t) 논문은 0 벡터로 masking
- **author feature** (5-dim, 연도별 업데이트):
  ```
  [paper_count, citation_count, cit/career_age, cit/paper_count, career_age]
  ```
- **엣지 (연도 t 기준)**:
  - `(paper, cites, paper)`: 누적 인용 방향 엣지
  - `(paper, cited_by, paper)`: 역방향
  - `(paper, written_by, author)`: t까지 출판된 논문-저자 연결
  - `(author, writes, paper)`: 역방향
- **레이블**: log(undirected degree + 1) per paper

#### 개선점 (기존 HetGNN 대비)
- paper-paper: GATConv → TransformerConv (QKV attention, 표현력 향상)
- paper-author: SAGEConv → GATConv (attention 기반 집계)
- author feature: SciBERT 평균(768) → 구조적 feature(5), 연도별 업데이트
- paper feature: temporal masking (미출판 논문 0벡터)
- author-paper 엣지: 시간 불변 → temporal 엣지

#### 학습 (train_node_split.py, train_temporal.py)
- GCN+LSTM_2의 train 파일과 구조 동일
- node_split: 노드 60/20/20, 활성 노드 마스킹 교집합으로 손실 계산
- temporal: LSTM state를 train→val→test로 이어받음

### 1-7. HeteroTCN

**위치**: `gnn/citation_prediction/hetero_tcn/`  
**날짜**: 2026-05-08

#### 개요
HeteroLSTM에서 시계열 모듈을 LSTM → Temporal Convolutional Network(TCN)으로 교체. Causal Dilated Conv + Residual 구조.

#### 모델 구조 (model.py)
- 클래스: `HeteroTCN`
- **Encoder**: HeteroLSTM과 동일 (TransformerConv + GATConv 2-layer)
- **TCN 블록** (`TCNBlock`):
  - `CausalConv1d`: left-padding으로 causality 보장하는 1D Conv
  - 2개 CausalConv1d + LayerNorm + Dropout + Residual 연결
  - dilations=[1,2] (receptive field = 1+(3-1)*1 + (3-1)*2 = 7)
  - kernel_size=3, dropout=0.1
- `encode(snapshots)` → (N, T, 256)
- `decode(z_seq)` → TCN(2 blocks, dilation 1,2) → head → softplus → (N, T)
- `forward_with_state(snapshots, hx)`:
  - hx = 이전 GNN 임베딩 컨텍스트 (N, T_prev, 256) (LSTM h/c tuple 아님)
  - z_all = concat(hx, z_new) → TCN → 마지막 T_new 타임스텝 pred 반환

#### 특이사항
- LSTM state 대신 GNN 임베딩 전체를 이어받아 context 유지 (HeteroTransformer와 동일 방식)

### 1-10. HeteroSubgraphGNN

**위치**: `gnn/citation_prediction/hetero_subgraph/`  
**날짜**: 2026-05-08

#### 개요

- 각 target 논문: 1-hop 인접 논문(인용/피인용) + 저자 포함
- Target 논문은 local index 0에 배치 (PyG batching 후 ptr로 접근)
- 레이블: log(Δcitations + 1), Δ = cum_cit(label_end) - cum_cit(τ)
- external_citations_by_year.json을 이용한 외부 인용 레이블
- train/val/test split은 SPLITS 설정(tau, label_end, pub_years)으로 정의

### 1-18. Patent Prediction — ptns (PTNS 모델, 논문 버전)

**위치**: `gnn/citation_prediction/patent_prediction/ptns/`  
**날짜**: 2026-05-15 ~ 2026-06-01

#### 개요
PTNS 논문의 Temporal Heterogeneous R-GCN + BiLSTM + Richards Curve 구조를 논문 버전으로 재구현. IPC 관련 레이어 포함.

#### 모델 구조 (model.py)
- 클래스: `PTNSModel`
- **노드**: patent, applicant, main_ipc, sec_ipc (4종)
- **엣지**: 8종
- **TemporalHeteroRGCNLayer** (논문 Eq.(2)):
  ```
  h_v = σ(W_0·x_v^curr + W_T·x_v^prev
         + Σ_r mean_{u∈N_r(v)} W_r·(x_u^curr + x_u^prev) + b)
  ```
  - W_r: relation별 가중치 (curr·prev 공유)
  - W_0: 현재 자기 연결, W_T: 이전 스냅샷 자기 연결
  - 2-layer TemporalHeteroRGCN, 스냅샷 순차 처리
- **BiLSTM**: cit_seq, auth_seq 각각 BiLSTM → 마지막 hidden
- **Richards Curve**: 4개 MLP head로 θ1, θ2, θ3, ξ 예측 → 비선형 성장 곡선 적합
  ```
  log_f = log(θ1) - (1/ξ) * log1p(ξ * exp(-θ2*(t-θ3)))
  pred = exp(log_f)
  ```
- 손실: RMSLE

```

[입력]
  - patent 노드: BERT 1024→PCA 128 + 수치 피처 = in_dim_pat

[Layer 1 — in_dim → gcn_hidden=128]
  patent 계열 (cross-snapshot 포함):
    W_self_1(proj_pat)                          # 현재 자기연결
    + W_cross_1(h_prev[citing_nbrs])            # 이전 스냅샷의 인용 이웃 (cross-snapshot 메시지)
    + scatter(global_id) → LayerNorm + ReLU
  IPC 계열 (main/sec 분리):
    W_high_ipc_1(main_ipc_agg)
    + W_low_ipc_1(sec_ipc_agg)
    + LayerNorm + ReLU
  Applicant 계열:
    W_high_app_1(applicant_agg)
    + LayerNorm + ReLU

[Layer 2 — gcn_hidden=128 → gcn_out=64]
  patent:
    W_self_2(h_cit_l1)
    + W_nbr_2(mean(h_cit_l1[current_citing_nbrs]))
  IPC: L1 임베딩 재사용 (W_high_ipc_2, W_low_ipc_2)
  Applicant: L1 임베딩 재사용 (W_high_app_2)
  모두 global scatter → LayerNorm + ReLU

[temporal 처리 — 스냅샷 순차 처리, prev_state detach]
  grad checkpoint로 메모리 절약
  출력: h_cit_seq [T_hist, N_pat, gcn_out]
       h_ipc_seq [T_hist, N_pat, gcn_out]
       h_app_seq [T_hist, N_pat, gcn_out]

[BiLSTM × 3 — 각 타입별 별도 BiLSTM]
  bilstm_cit: BiLSTM(64, 64, bidirectional=True) → last hidden [N, 128]
  bilstm_ipc: BiLSTM(64, 64, bidirectional=True) → last hidden [N, 128]
  bilstm_app: BiLSTM(64, 64, bidirectional=True) → last hidden [N, 128]
  청크 단위 처리(chunk_size=2000, cuDNN workspace OOM 방지)

[Aggregation]
  concat [h_cit, h_ipc, h_app] → [N, 384]
  fc: Linear(3*2*lstm_h=384 → pca_dim=64) + ReLU
  pca: Linear(64 → 64)                          # 명칭은 pca지만 Linear

[Richards Curve 파라미터 예측 — 4개 MLP head]
  head_θ1: Linear(64→32) + ReLU + Linear(32→1) → Softplus  (asymptote, >0)
  head_θ2: Linear(64→32) + ReLU + Linear(32→1) → Softplus+1e-6  (growth rate, >0)

  head_ξ:  Linear(64→32) + ReLU + Linear(32→1) → Softplus+1e-6  (shape, >0)

  Richards 예측:

    exp clamp(-50, 50) (수치 안정성)

[출력]
  [N_patent, T_pred] 예측 누적 피인용수

[Loss]
  RMSLE: sqrt(mean((log(ŷ+1) - log(y+1))²)) → 특허별 → 전체 mean

  def rmsle(pred, target):
      lp = torch.log1p(pred.clamp(min=0))
      lt = torch.log1p(target.clamp(min=0))

## 2. RGCN-GAT Link Prediction

**위치**: `/home2/jmbyeon/developments/20260625/RGCN-GAT-Link-Prediction/`

#### 개요
SJTU 과제 프로젝트(CS3319) — 학술 네트워크에서 저자-논문 링크 예측. author 6,611명, paper 79,937편, 엣지 타입 4종(ref, cite, coauthor, beref).

#### 모델 구조 (model.py)
- 라이브러리: DGL
- 클래스: `RGCN` (4-layer HeteroGAT), `ScorePredictor`, `Model`

**RGCN 구조**:
```
입력: {'author': (N_a, 512), 'paper': (N_p, 512)}

Conv1: HeteroGraphConv + GATConv (512→256, 8 head×32d, attn_drop=0.3)
       aggregate='mean'
       → LeakyReLU + BatchNorm1d(256) [author/paper 각각]

Conv2: HeteroGraphConv + GATConv (256→256, 4 head×64d)
       → LeakyReLU + BatchNorm1d(256)

Conv3: HeteroGraphConv + GATConv (256→256, 4 head×64d)
       → Tanh + BatchNorm1d(256)  ← Conv3부터 Tanh (내적 점수 안정화)

Conv4: HeteroGraphConv + GATConv (256→64, 2 head×32d)
       → 활성화 없음

출력: {'author': (N_a, 64), 'paper': (N_p, 64)}
```

**ScorePredictor**: 
- `u_dot_v('h', 'h', 'score')` — 두 노드 임베딩의 내적으로 엣지 연결 점수 계산
- 모든 엣지 타입에 동일하게 적용

**Model**: RGCN + ScorePredictor → pos_score, neg_score 반환 (margin loss)

#### 학습 (train.py)
- 4-hop neighbor sampling (blocks 4개)
- 파라미터: `--lr 2e-4 --wd 4e-4 --num_epochs 80`
- 소요: ~100-120분 (2080Ti/3070Ti)
- 손실: Margin Loss (pos_score > neg_score)

MANTF (nn.Module) — Multi-relational Adversarial Neural Tensor Factorization

    원고/피고 역할 마스크 (학습 가능 파라미터, sigmoid 활성화)
    → 원고용 임베딩 = comp_feat ⊙ sigmoid(mask_pla)
    → 피고용 임베딩 = comp_feat ⊙ sigmoid(mask_def)

[특허 임베딩 (MLP 기반)]
  _fc_title:   Linear(768, 768)  — BERT title 임베딩 투영
  _fc_abstract: Linear(768, 768) — BERT abstract 임베딩 투영
  _fc_claim:   Linear(768, 768)  — BERT claim 임베딩 투영
  _fc_text:    Linear(3×768=2304, 2304) — 3개 text 임베딩 concat 후 처리
  _mlp:        Linear(2304+100, factor_size=32) — text+meta(DeepWalk 100d) → factor_size
  
  patent_num: 89,552
  company_num: 19,772
  factor_size: 32
  bert_size: 768

[확률적 노이즈 (Variational Bayesian 스타일)]
  u_var, v_var, p_var, r_var: 학습 가능 파라미터 (분산)
  p_pla_emb = pla_feat + eps * sqrt(u_var)   (reparameterization trick)
  p_def_emb = def_feat + eps * sqrt(v_var)
  p_pat_emb = pat_emb  + eps * sqrt(p_var)

[소송 확률 예측]
  positive:
    p_res = Σ(pla_emb ⊙ def_emb) + Σ(pla_emb ⊙ pat_emb)
           + Σ(pat_emb ⊙ def_emb) + noise(r_var)
    → sigmoid(p_res)
  negative: 동일 구조, neg 샘플로

[Loss — BPR + 정규화]
  BPR:      -log(sigmoid(p_res - n_res))           → loss0
  emb_norm: λ0 * ||pla_emb||² + ||def_emb||² + ||pat_emb||²  → loss1
  sub_norm: λ1*||pla-pla_masked||² (원고 역할 정규화)

  pen_norm: λ4 * ||MLP 파라미터||²                 → loss4
  mcen_norm: λ5 * ||GCN 파라미터||²               → loss5
  total = loss0 + loss1 + ... + loss5

[음성 샘플 3종]

  neg_type=1: 피고(defendant) 무작위 교체
  neg_type=2: 특허(patent) 무작위 교체
```

  - 원고 특허 709개 / 피고 특허 672개 (GNN node_idx 보유)
  - split: train 2198 / val 145 / test 165
  - GNN 임베딩 4종: sage_fraud, gat, hetero_gat, hetero_sage (256-dim)
  - 특허 피처 22개

- **문제 정의 (2-Stage Retrieval → Ranking)**:
  - Stage 1 (Retrieval): 원고 특허 임베딩으로 코사인 유사도 기반 Top-K 후보 추출
  - Stage 2 (Ranking): LightGBM으로 pair 피처 기반 최종 랭킹

- **Stage 1 설계**:
  - GNN 임베딩 cosine similarity Recall@K 측정 (K=[10, 50, 100, 500, 1000])
  - MRR (Mean Reciprocal Rank) 계산

  ```
  cosine_sim_sage, cosine_sim_gat, cosine_sim_hetero_gat, cosine_sim_hetero_sage  (4개)
  |p_feat_i - d_feat_i| per feature                                               (22개)
  (p_feat_i + d_feat_i) / 2 per feature                                           (22개)
  → 총 48개 pair 피처
  ```
  - Positive: 실제 소송 쌍, Negative: 같은 원고의 hard negative 추출

- **GNN_CKPT_DIR**: `./data_gnn/gnn/`

- **발견된 문제**: 
  - GNN이 is_litigated(원고 여부)로 학습됨 → 피고 특허 대부분 label=0
  - 원고 특허 embedding과 피고 특허 embedding이 체계적으로 분리될 가능성 낮음
  - 해결 방향: 인용 그래프 기반 GNN (patent citation + company ownership 그래프)으로 재학습 필요
